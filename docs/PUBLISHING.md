# Publication notes

This is a prepared companion checkout, not evidence of a published GitHub or
Zenodo release. It combines the existing packages without changing their
distribution names or versions.

Before the first public release, choose the GitHub owner and repository name,
and review the included code and supporting material. Add the final URL to the package metadata and pipeline CITATION.cff
along with the verified release date. The existing citation identifies the
pipeline component; no DOI has been invented for this combined repository.
If an archived pipeline release is desired, decide whether to archive that
component separately or cite an archive of the whole companion repository.

Run the root README's offline checks. After the destination is chosen, create
the GitHub repository and push this checkout. The existing source repositories
do not need to be changed. Preserve the upstream material audits, licenses,
source hashes, and reviewed result manifests when publishing.

The blog pages are already published and are not bundled here. The companion
contains code, examples, source audits, and reviewed results. External source
URLs have not been freshly verified during repository assembly.
